# Trigger cases: wrap-up

Should start the skill:

- "That's it for today."
- "Wrap up."
- "Before I clear you, make sure nothing is lost."
- "Is anything still dangling?"

Near misses, with what handles each:

- "What's running?" → look at the sessions and answer.
- "Close the login task." → `finish`.
- "Remember what we learned this week." → `consolidate`.
