# Research

**Use when** the user wants to know what is known outside their own projects: documentation, the web, how other
projects do something. A question about their own systems is Investigate.

**Steps**
1. **Laima** narrows the question when it is too wide to answer in one note: ask the user what decision it feeds.
2. **Researcher** (`roles/researcher.md`): launch with the question and what is already known; a question
   about no project of the user's starts in its task folder (`launch` step 1).
3. **Laima** reads the note and checks that the claims the answer rests on carry sources.
4. **Laima** delivers the answer with the sources. When the note will matter beyond this task, promote it to
   `local/Laima/knowledge/` (marked `origin: external`) and log `promoted`.

**Ask the user** only to narrow the question.

**Done when** the user has the answer with its sources, and the note is promoted, kept where `finish` step 3 puts
a deliverable when the user asked for it as a file, or left to go with the task folder. Outcome `answered`.
